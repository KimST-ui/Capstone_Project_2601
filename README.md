# The Soc Capstone Projcet
=============================================================
## Arm-based Soc Implementation Project
---------------------------------------

🐚건양대학교 2026학년도 Soc Capstone_Project

📂 Phase 1. 하드웨어 설계 기초 (PL Design)
01주 | SoC 개요 : Orientation & SoC 구조에 대한 기본 고찰
02주 | 환경 구축 : Development Environment Configuration (Vivado/Vitis)
03주 | 로직 설계 (1) : Basic Programmable Logic Design (조합 논리)
04주 | 로직 설계 (2) : Basic Programmable Logic Design (순차 논리FSM)

📂 Phase 2. 시스템 아키텍처 (System Architecture)
05주 | 프로세서 통합 : ARM Cortex A-9 Instantiation & AMBA 인터페이스
06주 | PS 설계 (1) : Basic Processing System Design (IP 설정)
07주 | PS 설계 (2) : Basic Processing System Design (연동 및 주소 할당)
08주 | 🚩 중간고사 : Midterm Exam

📂 Phase 3. 소프트웨어 제어 및 가속기 (PS/PL Control)
09주 | 베어메탈 C (1) : Bare Metal C Programming (레지스터 제어)
10주 | 베어메탈 C (2) : Bare Metal C Programming (인터럽트 및 주변장치)
11주 | 산술 가속기 : SoC PL Design (Arithmetic Accelerator 설계)
12주 | 메모리 컨트롤러 : SoC PL Design (BRAM Controller & Interface)

📂 Phase 4. 시스템 검증 및 완료 (Final Phase)
13주 | 시스템 검증 (1) : SoC PS Control and Verification (디버깅)
14주 | 시스템 검증 (2) : SoC PS Control and Verification (최적화)
15주 | 🏆 프로젝트 발표 : Capstone Presentation
16주 | 🏁 기말고사 : Final Exam
